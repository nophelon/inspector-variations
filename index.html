에디터 화면 디자인 베리에이션

상단바 · 왼쪽 페이지 패널 · 오른쪽 "배경 설정" 인스펙터를 포함한 전체 편집 화면. 브랜드 컬러 #D646AC. 각 카드를 열어 라이트/다크로 확인하세요.

F1 충실 재현

레퍼런스(image3) 그대로 — 활성 "배경"이 마젠타 풀 pill, 하위(이미지·동영상·색상)는 세로 연결선 트리, 동영상이 흰 선택 pill. 상단바·페이지 패널도 같은 둥근 톤.

F2 아이콘 레일 + 패널

인스펙터 왼쪽에 아이콘 레일(배경·모바일·색상), 선택 항목만 오른쪽 패널에 펼침. 한 화면에 더 많이 담기는 2단 구성.

F3 섹션 라벨 그룹

떠있는 pill 대신 평평한 설정-앱 느낌. 회색 대문자 라벨로 "배경 유형 / 모바일 전용 / 배경 색"을 묶고, 유형은 세그먼트로 전환.

F4 3섹션 동시 노출

아코디언을 열고 닫지 않고 배경·모바일 영상·배경 색 세 소프트 카드를 항상 함께 노출. 클릭 수 최소.

F5 컴팩트

F1과 같은 구조를 간격·반경·글자만 줄여 밀도를 높임. 페이지가 많거나 작은 화면에서 한눈에.
